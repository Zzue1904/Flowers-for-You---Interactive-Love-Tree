# 🌼 Flowers for You

An interactive web experience built with HTML, CSS, and JavaScript.

The project starts with a single flower and transforms it into a growing tree filled with yellow flowers. The experience ends with a live love counter and a personal message.

## ✨ About the Project

"Flowers for You" was created as a small interactive web experience combining animation, visual storytelling, and personal design.

The experience follows a simple sequence:

1. 🌼 A flower appears with an invitation to click.
2. 🌱 The flower transforms into a seed.
3. 🌳 A tree grows from the seed.
4. 🌿 Branches and smaller twigs appear progressively.
5. 🌼 Yellow flowers bloom across the tree.
6. 🍂 Some flowers fall from the tree.
7. 🔭 The camera zooms out.
8. ❤️ A live counter shows how much time has passed since February 14, 2025.
9. 💌 A final message appears.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- CSS animations
- JavaScript DOM manipulation
- JavaScript Date API

## 🎨 Features

- Interactive flower-to-seed transition
- Animated tree growth
- Progressive branch and twig animations
- Custom CSS flowers
- Heart-shaped flower arrangement
- Falling flower animation
- Zoom-out transition
- Live days, hours, minutes, and seconds counter
- Animated final message
- Responsive layout
